# slooves.si - notes for Claude

Read `README.md` first: file layout, brand colours and fonts, how the folk
strip is fitted, QR code, local preview.

## Rules

- This repository is public. Keep everything in it (code comments, README,
  commit messages) short, factual and technical. Planning notes, drafts,
  contacts and handoff summaries belong in the private notes, not here.
- `README.md`, `CLAUDE.md` and other non-site files are kept off slooves.si by
  `_config.yml`. Add any new non-site file to its `exclude` list.
- A push to `main` publishes the site. Commit messages are short Slovenian
  sentences without diacritics (see `git log`).
- Commit as `Globocnik0 <76513873+Globocnik0@users.noreply.github.com>`.
- Site copy is the family's own Slovenian text. Put it in verbatim; point out
  typos, but ask before changing wording.
- Style: plain hyphens as on the packaging, no em dashes.
- Packaging text and colours come only from the final print file of the
  carton (location in the private notes), not from earlier drafts. Its text
  is outlined, so read it from a rendered page.
- Strip height must be a whole number of device pixels (see README) - check
  any strip change at desktop and at ~360/390/430 px phone widths.
